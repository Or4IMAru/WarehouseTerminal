# Вариант 10. Складской терминал

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Legacy, процессы, async, синхронизация, DLL, реестр

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Создать модель товара и складского остатка.
2. Реализовать приход и расход товара.
3. Обработать несколько операций одновременно без потери обновлений.
4. Добавить импорт накладной из текстового файла асинхронно.
5. Запустить внешнюю программу-валидатор через Process.
6. Вынести складскую логику в DLL и подключить её через ProjectReference.
7. Сохранять настройки склада в HKCU.

## Дополнительные задания
8. Добавить адаптер для старого формата накладной.
9. Реализовать очередь операций через Channel.
10. Сформировать параллельный отчёт по категориям.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
